# Hivemind

**Continual-learning org memory for AI coding agents.**
Every correction any engineer gives any agent becomes a lesson every agent at the company learns from — safely, with a chain of command.

Built for SEP Hacks 2026 (Grand Tech: Continual Learning track).

**Live:** https://hivemind-beta-virid.vercel.app (website) · https://hivemind-beta-virid.vercel.app/app (the app). Every push to `main` deploys.
